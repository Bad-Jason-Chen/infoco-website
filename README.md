# InfoCo Website

InfoCo 计算机社团官网，正式域名为 [infoco.club](https://infoco.club)。

## 页面

- 首页：社团定位、当前通知、精选项目与活动记录
- 关于我们：使命、文化、发展时间线、团队与常见问题
- 活动：活动预告、往期筛选与活动详情
- 项目与作品：项目状态、技术标签与协作者状态
- 游戏中心：模式说明与 `InfoCo.exe` 互动游戏
- 加入我们：招新状态、适合方向、流程和常见问题

## 本地开发

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 内容维护

结构化活动和项目数据位于 `app/content.ts`。当届负责人、公开联系方式、真实活动日期与活动照片需要在获得社团确认或公开授权后再更新，避免发布私人或未经确认的信息。
